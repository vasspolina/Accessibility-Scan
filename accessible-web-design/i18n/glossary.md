# Do not translate

These keep their exact form in every locale. A translator who "localises"
one of them has introduced a bug, not a translation.

## Names
- BarrierFreeWeb
- Accessibility Scan
- axe-core
- WCAG
- EAA — but see below: the *expansion* is localised
- BFSG, BFSGV
- EN 301 549
- RGAA
- Equality Act 2010

## Standards: the official name in the target language

A standard's name is not a phrase to translate — it is the name the reader
will search for and the auditor will cite. Use the official name in the
target language, never a literal rendering.

| Concept | en | de |
|---|---|---|
| European Accessibility Act | European Accessibility Act (EAA) | European Accessibility Act (EAA) — German law implements it as the BFSG |
| Barrierefreiheitsstärkungsgesetz | Barrier-Free Strengthening Act (BFSG) | Barrierefreiheitsstärkungsgesetz (BFSG) |
| Accessibility statement | Accessibility statement | Barrierefreiheitserklärung |
| WCAG success criterion titles | W3C English | W3C Authorized German Translation — never our own rendering |

## Terminology: one term per concept, site-wide

Decided once. Mixing two words for one thing reads as two things.

| Concept | en | de |
|---|---|---|
| the check we run | audit | Prüfung |
| the document it produces | report | Bericht |
| a thing found | finding | Befund |
| a barrier for a user | barrier | Barriere |
| screen reader | screen reader | Screenreader |
| alt text | alt text | Alt-Text |
