fallback would be English inside a German report. Each needs a native ear
for register (Sie), the house voice, and whether the short labels read
naturally as buttons and badges. Edit the right-hand column in
`widget-business/src/lib/strings.de.ts`; the Spanish and French siblings
carry the same keys and the same caveat.
